Foundations

Theming and tweaks

Fire's whole look runs on variables: fifteen palettes recolour every neutral and the accent, tone bends whichever palette you pick, twelve type sets change the voice of the headings and the interface, and a handful of scales set density, corners, lines, text size and motion. The Tweaks panel turns all of it into live controls.

Tweaks panel

Use it to find a product's character before you commit to it, or ship it so your users can tune density, contrast and motion for themselves. It floats beside the page and is not modal, so every change can be watched on the real screen.

  • Any element with data-fd-tweaks-open toggles the panel and carries its aria-expanded state. The docs top bar has one.
  • No trigger of your own? Put data-fd-tweaks on <html> and a round launcher appears bottom-left.
  • Choices are saved in localStorage["fd-tweaks"] (only what differs from the default) and applied as soon as the module runs. Load fire/boot.js as a plain (non-module) script in <head>, before the stylesheet, and the saved look is on <html> before the first paint, so a reload never flashes the default. Reset leaves no attribute or inline style behind.
  • The page's own look is the default. A page that declares data-palette or data-type on <html> keeps it on load and after Reset, and only a choice away from it is saved; a page that declares nothing defaults to Ember and Geist. Before fire/boot.js restores a saved palette or type set it keeps the page's values in data-fd-default-palette and data-fd-default-type, so the panel still knows them; never write those by hand.
  • Copy CSS gives you a block to paste into your product: the attributes for <html> and a :root rule with every overridden variable, toned palette colours included. A type set is just an attribute, so it needs fire/typefaces.css (already part of fire.css).
  • Keyboard: Tab moves between controls, arrows move inside a group (the palette grid is 5 × 3 and the typeface grid 4 × 3), Escape closes the panel and returns focus to its trigger. On desktop the header drags; double-click it to dock again. Under 640px it is a bottom sheet.
JavaScriptDoes
open(trigger) · close() · toggle(trigger)Show or hide the panel. Focus returns to trigger on close.
get()The full state: { palette, type, tone, theme, density, corners, lines, textSize, contrast, motion, texture }.
set(partial)Merge and apply, for example set({ palette: "paper", type: "editorial", tone: { warmth: 30 } }). Unknown or out-of-range values are ignored or clamped.
reset()Everything back to the page's own look: its declared palette and type set, otherwise Ember and Geist.
toCss()The Copy CSS text for the current state.
fd:changeFires on <html> after every change with detail: { name: "tweaks", value: state }.

Palettes

A palette is one attribute, data-palette, on <html> or any subtree. It sets the page, surfaces, lines, ink and accent for both themes, so every component inside takes its colour without a line of extra CSS. The neutrals are tinted to match the accent, so greys read as stone, slate or sand rather than one grey with a new accent.

Typefaces

A type set is one attribute, data-type, on <html> or any subtree. It sets three voices together: --fd-font-display for headings, --fd-font-sans for the interface and --fd-font-mono for code, keys and eyebrows, plus how the headings are tracked and weighted in that face. Pick one to change a product's character without touching a component.

Tone

Tone bends the chosen palette instead of replacing it: rotate the accent toward your brand, mute it, lift it, or warm the page. At zero every control is exactly the palette. Try one on this page:

ControlRangeWhat it does
hue−180° to 180°Rotates the accent, its hover, its text colour and the primary button's inner shade, in OKLCH, so lightness holds while the colour turns.
vivid0% to 150%Scales the accent's chroma. 0% is a grey accent; above 100% it saturates until the screen's gamut stops it.
light−12 to 12Shifts the accent's lightness by that many hundredths of L.
warmth−100 to 100Tints the page, surfaces, lines, ink and washes toward blue or yellow-orange. At ±100 the page is clearly tinted but still neutral; the whitest surface takes the least.
  • After every bend the engine re-applies the palette rules: accent text stays at 4.5:1 or more on the page and on surfaces, and the label on the accent keeps its colour while it reaches 3:1, switching between white and near-black when it would not.
  • Ink on the page stays at 12:1 or more in every palette and theme.
  • A toned palette is written as inline variables on <html>; Copy CSS writes the same values out as a palette you can keep.

Scales

The character variables multiply every token in their family, so one number retunes the whole system. Set them on :root, or on a subtree together with data-scale so the derived tokens recompute there.

VariableDefaultWhat it changes
--fd-space-scale1Every --fd-space-* step. Density sets it to 0.875 or 1.125.
--fd-radius-scale1Every radius except full: 0 is square, 2 is soft and round. The panel steps it by 0.125.
--fd-motion1Every duration (--fd-dur-* and timed component tokens). 0 turns motion off; reduced motion sets it for you.
--fd-texture1Strength of the generative textures, 0 to 1.5.
--fd-hairline1pxThe width of every rule, edge and ring.
--fd-font-displayvar(--fd-font-sans)The face of headings and display type. A type set points it at the set's headings face; set it by hand only for a one-off.
--fd-weight-display500The weight of headings. A type set may ask for a heavier or lighter cut, so a condensed face can run at 800 and a serif at 500.
data-type(geist)A type set, on <html> or any subtree: it sets the headings, interface and mono faces together with the heading tracking and weight. Geist needs no attribute.
data-densitycomfortablecompact or spacious: control and row heights, control padding, the gutter and the space scale.
data-contrast(none)high strengthens muted text, lines and control edges.
data-text-size(md)sm or lg on <html>: the root size, so everything set in rem follows.

Make your own palette

A palette sets nineteen tokens, each as a light-dark() pair. Start from Copy CSS in the panel (pick the nearest palette, tone it, copy) and rename the block.

  • Page and surfaces: --fd-bg, --fd-bg-sunken, --fd-surface, --fd-surface-raised, --fd-surface-inverse, --fd-scrim, --fd-thumb. Keep surfaces lighter than the page in both themes.
  • Lines: --fd-line-faint, --fd-line, --fd-line-strong.
  • Ink: --fd-ink, --fd-ink-inverse, and the two wash colours. --fd-wash makes every fill and tint (its alpha steps are --fd-a1 to --fd-a24); --fd-ink-wash makes every text step (--fd-a32 to --fd-a88). Give both a little of your neutral hue.
  • Accent: --fd-accent, --fd-accent-hover, --fd-accent-contrast (the label on it), --fd-accent-text (AA on the page), --fd-accent-glow (the primary button's inner shade).
  • Everything else derives by itself on [data-palette]: the ink ladder, text steps, fills, accent washes, the focus ring and the primary button's shadow.
