# Fire class vocabulary (agreed names across families)

Use these exact names. If you own a family, implement every name listed under it (you may add more).
If you need another family's component in a demo, use its name from this list; it will exist.

- **Base (done)**: `fd-display fd-h1 fd-h2 fd-h3 fd-title fd-label fd-body fd-small fd-caption fd-stat fd-mono fd-mono-sm fd-eyebrow fd-muted fd-faint fd-link fd-icon fd-kbd fd-code fd-stack fd-row fd-grow fd-grid fd-divider fd-truncate fd-sr-only fd-rise fd-cq`
- **Buttons (done)**: `fd-btn` (`data-variant="primary|outline|ghost|inverse|accent-soft|danger|danger-soft"`, `data-size="xs|sm|lg|xl"`, `data-icon-only`, `data-block`, `aria-busy`), `fd-btn-group`, `fd-btn-text`, `fd-fab`
- **Shell**: `fd-app` (root grid; `data-sidebar="expanded|collapsed"`), `fd-sidebar`, `fd-sidebar-head`, `fd-sidebar-body`, `fd-sidebar-foot`, `fd-brand` (`fd-brand-mark` holding an inline SVG or an `img`, `fd-brand-name`, or `fd-brand-logo` for a wide image in place of both), `fd-wordmark` (a logotype in the current colour; `data-size="sm"`, `data-tone="accent"`), `fd-nav`, `fd-nav-label` (section eyebrow), `fd-nav-item` (`aria-current="page"`), `fd-nav-group` (expandable), `fd-nav-badge`, `fd-usage-card`, `fd-account` (user row), `fd-topbar`, `fd-team-switch`, `fd-main`, `fd-page`, `fd-frame` (blueprint column with rails + crosshair marks), `fd-band` (a full-width framed section inside the frame; `data-align="center"` puts its content in the middle of a grown band), `fd-screen` (the centred screen for one task: brand, card, note; `data-size="md"`; parts `fd-screen-head`, `fd-screen-note`), `fd-page-hero` (+ `fd-page-hero-art`, `fd-page-hero-desc`, `fd-page-hero-actions` under the line; wrap the eyebrow, title and line in `fd-page-hero-text` and the `fd-page-hero-actions` after it sit at the end of the title row, dropping under on a phone), `fd-page-head` (compact title row), `fd-toolbar`, `fd-split` (content + side panel), `fd-panel`, `fd-mobile-nav`
- **Navigation**: `fd-tabs`/`fd-tab` (underline), `fd-segmented`/`fd-segmented-item` (sliding thumb; in a form an item is `<label class="fd-segmented-item"><input type="radio" name value><span>…</span></label>`, which posts and works without script; a track narrower than its items scrolls, `data-block` shares the width equally), `fd-chip-nav`/`fd-chip` (icon + label category strip, scrollable), `fd-subnav`/`fd-subnav-item` (settings side nav), `fd-breadcrumb`, `fd-back`, `fd-pagination`, `fd-steps`/`fd-step` (wizard), `fd-toc`
- **Forms**: `fd-field` (`fd-field-label`, `fd-field-hint`, `fd-field-error`), `fd-input`, `fd-textarea`, `fd-select` (styled native), `fd-input-group` (`fd-input-affix`), `fd-search`, `fd-checkbox`, `fd-radio`, `fd-switch`, `fd-slider`, `fd-number`, `fd-combobox`, `fd-tag-input`, `fd-choice` (radio/checkbox card), `fd-secret` (masked value + reveal/copy/rotate; `data-mask="partial|full|end"`, with `end`: `data-mask-from` (keep the start up to this text), `data-mask-keep` (last N shown, 4); drawn as `fd-secret-start` + `fd-secret-end`; `data-mode="entry"` > `input.fd-secret-input` + a reveal button, to type a new secret), `fd-copy-field` (same masks; `fd-copy-field-start` + `fd-copy-field-end`), `fd-dropzone`, `fd-otp` (`data-length`, `data-type="alphanumeric"`, `data-size="sm"`; in a posted form, `data-name` or one plain named input inside), `fd-form-row` (label left, control right), `fd-form-actions`, `fd-form-section` (`fd-form-section-head`, `fd-form-section-title`, `fd-form-section-desc`, `fd-form-section-body`; `data-layout="stack"`: the pattern for a long create or edit form), `fd-pairs` (names with values; wraps one named text area, `data-fd-pairs`, `data-format="json"`, `data-key-label`, `data-value-label`, `data-add-label`, `data-mono`; parts `fd-pairs-head`, `fd-pairs-row`, `fd-pairs-key`, `fd-pairs-value`, `fd-pairs-add`), `fd-codefield` (raw code for experts; `fd-codefield-head`, `fd-codefield-lang`, `fd-codefield-input`, `data-fd-json`, `data-fd-codefield-format`). `fd-tag-input` may wrap one named text area and then posts in a plain form (`data-format="json"` for a JSON array). `<span class="fd-input">` is a value shown in a field's shape. Choose controls with the table in `GUIDE.md` section 5: never a text box for a choice, a switch, a list or pairs, and never JSON outside `fd-codefield`
- **Overlays**: `fd-menu`/`fd-menu-item`/`fd-menu-label`/`fd-menu-sep`, `fd-popover`, tooltips via `data-fd-tooltip="text"` (`fd-tooltip`), `fd-dialog` (`fd-dialog-head|body|foot`), `fd-sheet` (side drawer / bottom sheet), `fd-toast` (API `toast({title, description, tone, action})`), `fd-command` (⌘K palette), `fd-confirm` (type-to-confirm), `fd-hovercard`
- **Data**: `fd-table` (+ `fd-table-wrap`, `fd-th-sort`; row actions in `td[data-actions]`: ghost buttons are quiet until the row is hovered or focused, any other variant is full strength), `fd-list`/`fd-list-row`, `fd-kv` (key-value grid), `fd-stats`/`fd-stat-tile` (figure `fd-stat`; `fd-stat-row` > `fd-stat` + `fd-stat-delta`, or + `fd-stat-unit` for a small unit on the figure's baseline), `fd-meter`, `fd-progress`, `fd-filter` (filter trigger chip), `fd-filter-bar`, `fd-table-foot`, `fd-pipeline` (staged work: stages left to right, parallel jobs stacked, CSS connectors; `data-size="sm"`, `data-orientation="vertical|horizontal"`, `data-fd-pipeline="manual"`, `aria-busy`; parts `fd-pipeline-stages` (ol), `fd-pipeline-stage` (li, `data-when` for a conditional stage), `fd-pipeline-stage-label`, `fd-pipeline-jobs` (ul of li), `fd-pipeline-job` (button, `a[href]` or span; `data-value`, `data-tone="neutral|success|danger|warning|info|violet"`, `data-live`, `data-state="skipped"`, `aria-current`; an icon first and an `fd-sr-only` status word), `fd-pipeline-job-name`, `fd-pipeline-job-meta`; emits `fd:select` `{ value, item }`)
- **Content**: `fd-card` (`data-interactive`), `fd-badge`, `fd-status` (dot + label, `data-tone`, `data-live`), `fd-tag`, `fd-avatar`/`fd-avatar-stack`, `fd-tile` (logo/glyph tile), `fd-qr` (a code to scan, light in both themes; `data-size="sm|lg"`), `fd-callout`, `fd-banner`, `fd-empty`, `fd-accordion`/`fd-disclosure`, `fd-timeline`, `fd-setting` (settings row: text left, control right), `fd-plan` (pricing/plan card), `fd-feature-list`, `fd-verified`
- **Code**: `fd-codeblock` (`fd-codeblock-head`, tabs, copy), `fd-snippet` (one-line command + copy), `fd-json` (collapsible tree), `fd-log` (log/terminal viewer; `data-fit`: the body fits its lines up to the usual height, then scrolls), `fd-diff`, `fd-endpoint` (method + path pill), `fd-schema` (params table)
- **Agent**: `fd-composer`, `fd-composer-tools`, `fd-model-chip`, `fd-suggestions`, `fd-thread`, `fd-message` (`data-role="user|assistant"`), `fd-toolcall`, `fd-reasoning`, `fd-sources`/`fd-citation`, `fd-run-steps`, `fd-cursor` (streaming caret), `fd-playground` (request/response), `fd-session-list`
- **Chat**: `fd-chat` (`data-mode="panel|popup|inline|side"`, `data-state`, `data-contained`, `data-expanded`, `data-agent`), `fd-chat-launcher` (+ `fd-chat-launcher-icon`, `fd-chat-launcher-badge`), `fd-chat-teaser`, `fd-chat-head` (`fd-chat-who`, `fd-chat-mark`, `fd-chat-title`, `fd-chat-status`, `fd-chat-actions`), `fd-chat-banner`, `fd-chat-body`, `fd-chat-view` (`data-view="home|conversation|history|offline"`), `fd-chat-home` (`fd-chat-greeting`, `fd-chat-intro`, `fd-chat-suggestions`, `fd-chat-continue`, `fd-chat-links`, `fd-chat-service`), `fd-chat-pill`, `fd-chat-log`, `fd-chat-msg` (`data-author="user|ai|human|system"`; `fd-chat-msg-avatar|main|head|name|role|time|stamp|quote|body|reactions|meta|actions`), `fd-chat-block` (`data-type`: text, quick-replies, actions, card, carousel, list, form, details, table, code, attachment, sources, tool, steps, confirm, handoff, rating, schedule, metric, notice), `fd-chat-panel`, `fd-chat-receipt`, `fd-chat-reaction`, `fd-chat-typing`, `fd-chat-jump`, `fd-chat-history`/`fd-chat-thread`, `fd-chat-offline`, `fd-chat-foot` (`fd-chat-quote`, `fd-chat-closed`, `fd-chat-disclaimer`), `fd-chat-drop`, `fd-chat-lightbox`
- **Charts**: `fd-chart` (`data-fd-chart="line|area|bar|stacked"`), `fd-sparkline`, `fd-bars`, `fd-donut`, `fd-heatgrid` (`data-variant="strip"`: one row of days with a tone each, JSON `tones`/`legend`/`hrefs`, `data-size="sm"` for a table cell), `fd-legend`, `fd-chart-tooltip`
- **Texture & loading**: `fd-ascii` (`data-fd-ascii="terrain|waves|orbit|rain|grid|flame"`, fills its parent), `fd-dotgrid`, `fd-spinner`, `fd-braille`, `fd-dots`, `fd-skeleton` (+ presets `fd-skeleton-text|title|avatar|button|card|table|stat|chart|thread`), `fd-shimmer`
- **Documentation**: `fd-doc` (`data-contained`; `fd-doc-top`, `fd-doc-search`, `fd-doc-nav`/`fd-doc-nav-item`, `fd-doc-method`, `fd-doc-main`, `fd-doc-article`, `fd-doc-aside`, `fd-doc-toc`, `fd-doc-otp`), `fd-doc-head`, `fd-prose`, `fd-doc-frame`, `fd-doc-cards`, `fd-doc-steps`, `fd-doc-tabs`, `fd-doc-setup`, `fd-doc-ask`, `fd-doc-params`/`fd-doc-param`, `fd-doc-response`, `fd-doc-api`, `fd-doc-endpoint`, `fd-doc-panel`, `fd-doc-try`, `fd-doc-foot`, `fd-doc-pager`, `fd-doc-footer`, `fd-doc-changelog`/`fd-doc-release`, `fd-doc-hero`; `.fd-codeblock[data-variant="framed"]`
- **Tweaks**: `fd-tweaks` (the floating panel: `fd-tweaks-head`, `fd-tweaks-title`, `fd-tweaks-reset`, `fd-tweaks-body`, `fd-tweaks-section`, `fd-tweaks-row`, `fd-tweaks-palettes`/`fd-tweaks-swatch`, `fd-tweaks-tone`, `fd-tweaks-value`, `fd-tweaks-foot`, `fd-tweaks-summary`), `fd-tweaks-launcher`; triggers `[data-fd-tweaks-open]`, `<html data-fd-tweaks>` for the launcher; palettes `data-palette="ember|volt|iris|ocean|forest|graphite|rose|honey|plum|lagoon|paper|clay|mint|glacier|midnight"`; type sets `data-type="geist|grotesk|editorial|book|atelier|poster|terminal|pixel|matrix|cyber|loud|gallery"` (`fire/typefaces.css`); `fire/boot.js` restores the saved look before first paint; the page's own `data-palette` / `data-type` are the defaults (load, Reset, what is saved), and `boot.js` keeps them in `data-fd-default-palette` / `data-fd-default-type` before it restores a saved look (written by `boot.js`, empty when the page declared none; not written by hand)
- **Layout**: primitives `fd-stack` (`data-align="start|center|end"`), `fd-row` (`data-wrap`, `data-justify="between|end|center"`, `data-align="start|end|baseline|stretch"`), `fd-grid`, `fd-column` (`data-size="xs|sm|md|lg|xl"`, `data-align="center"`), `fd-grow`; attributes on any element (`fire/layout.css`): `data-gap` / `data-gap-x` (space steps `0 … 24`), `data-min` (size steps `4xs … 6xl`, `full`), `data-cols` (`1`–`6`), `data-span` (`2`–`6`, `full`). Width comes from structure and component variants: `fd-form` / `fd-form-cols` (`data-size="sm|lg|full"`), `data-fit` on `fd-input` / `fd-input-group` / `fd-select` / `fd-number` / `fd-search`, `fd-setting[data-control="wide"]`, `th[data-col="fit|sm|md|lg|fill"]`, `fd-table-trunc[data-size="sm|lg"]`, `fd-table-skeleton[data-size="2xs|xs|sm|md|lg|xl"]`, `fd-playground-bar[data-size="sm"]`, `fd-corners[data-size="sm|md|lg|xl"]`, `fd-composer-hero[data-size="sm"]`, `fd-toolbar-search[data-size="full"]`. Never a width, a height or px in markup. Docs pages only: `data-frame`, `data-frame-h` (preview frames, stripped from the code view).
