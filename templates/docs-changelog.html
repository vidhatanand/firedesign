Changelog

New endpoints, SDK releases and fixes, newest first. Subscribe with the RSS feed or the changelog.updated webhook.

  1. Nov 12, 2026v2.14.0
    NewAPI

    Monitors are generally available

    Point a monitor at any URL, choose what counts as a change, and Ember sends a webhook with the diff. Monitors run every 5 minutes to every 7 days and cost one credit per check.

    • New endpoints: POST /v2/monitors, PATCH /v2/monitors/{id} and DELETE /v2/monitors/{id}.
    • The monitor.changed webhook carries a unified diff and the two Markdown versions.
    • Ignore rules let you skip timestamps, prices or any CSS selector.
  2. Nov 5, 2026v2.13.2
    ImprovedSDKs

    Typed JSON in the Python and Node SDKs

    Pass a Pydantic model or a Zod schema straight to formats. The SDKs convert it to JSON Schema and return a typed object, so you no longer validate the response yourself.

  3. Oct 29, 2026v2.13.1
    FixedAPI

    Crawls no longer stall on sitemap index files

    Sites that split their sitemap across nested index files could leave a crawl waiting at 0 pages. Crawls now follow up to three levels of index files and report skipped ones in warnings.

    Affected crawls from the last 30 days were refunded automatically.

  4. Oct 21, 2026v2.13.0
    NewImprovedAPI

    Interact sessions and faster stealth proxies

    After a scrape, keep the browser open with POST /v2/scrape/{scrapeId}/interact and drive it with a prompt or code. Sessions bill 2 credits per minute and close after 10 idle minutes.

    Stealth proxies now pick a region near the site, which cut the median time to first byte from 2.1 s to 1.3 s.

  5. Oct 8, 2026v2.12.0
    ImprovedSDKs

    The CLI signs in from the browser

    ember login now opens the browser and stores the key in the system keychain. Pass --key for CI, where there is no browser.
