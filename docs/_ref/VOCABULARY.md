# Fire class vocabulary (agreed names across families)

Use these exact names. If you own a family, implement every name listed under it (you may add more).
If you need another family's component in a demo, use its name from this list; it will exist.

Type spec attributes: `data-heading-case="upper"`, `data-figures="tabular"`.
- **Theme record**: `{ "contract": "fire/1", "palette", "tone", "type", "dials", "signature" }` (`contract/theme.schema.json`); `type` is a set name or a spec (`display`, `sans`, `mono`, `displayWeight`, `displayTracking`, `headingCase`, `figures`) from the families in `contract/fonts.json`; `dials` gains `surfaces`, `elevation`, `controls`, `headings`; `signature` is `{ field, mark, cell, ramp, marks, intensity }`; `expandTheme`, `themeToCss`, `paletteFrom`, `validateTheme` from `fire/js/theme.js`; Tweaks' "Copy theme" copies one.
- **Modules** (no class; each has a card in the catalogue): `renderEmail({ theme, brand, preheader, blocks, locale })`, `emailColors(theme)` and `isRtl(locale)` from `fire/email/email.js` (blocks `heading`, `text`, `button`, `code`, `keyValue`, `divider`, `note`, `footer`); `initialMark`, `initialRows`, `initialTone`, `initialChar` from `fire/js/initial.js`; the theme record's exports above.
- **Events added in 0.7**: `fd:accept` (a draft used), `fd:commit`, `fd:hold`, `fd:undo` (a held action), `fd:download` (recovery codes), `fd:keys` (a key sequence ran). `fd:select`, `fd:change`, `fd:open`, `fd:close` and `fd:hover` also fire for the parts named above.

Custom elements (not a family: each one is the root of a component above, and the catalogue maps it there): `fd-icon` (`icon`, `size`), `fd-chart` (`type`, `.data`), `fd-code` (`language`, `.code`), `fd-texture` (`pattern`, `marks`, …). Each element is its component's root and carries the root class (`fd-icon`, `fd-chart`, `fd-codeblock`, `fd-ascii`); use them in framework code, and the markup form on plain or server-rendered pages. The full list of attributes, properties and events is `contract/custom-elements.json`.
- **Looks** (not classes): a look is a named, complete theme record (`steady`, `operator`, `folio`, `hearth`, `instrument`, `marquee`, `gentle`, `clear`; `contract/looks/named`, `LOOKS` in `fire/js/looks.js`). `?look=<name>` applies one before first paint and sets `data-fd-look` on `<html>`; Tweaks' Looks row applies one whole.
