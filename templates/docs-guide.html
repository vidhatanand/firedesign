Introduction

The context API for AI agents. Search the web, scrape any page, and interact with it through one API.

Ember turns the live web into clean Markdown or structured JSON your agent can use. Search, scrape and interact with any page, including the ones that need JavaScript, a login wall or a few clicks before the content appears.

Get started

Set up Ember MCP

Sign in through your browser. No key to paste.

See all setup options

Install the Ember plugin, or add the MCP server directly with the command below.

Add to Claude Code
$claude mcp add ember --transport http https://mcp.ember.dev/v2/mcp

Then run /mcp in Claude Code and check that ember shows as connected.

Register the server once; every Codex session on this machine can use it.

$codex mcp add ember --url https://mcp.ember.dev/v2/mcp

Codex opens your browser to sign in. Run codex mcp list to confirm.

Cursor asks to install the server, then signs you in through the browser.

Add to Cursor

Prefer a config file? Add the URL below to .cursor/mcp.json.

Add Ember as a remote server in any client that supports streamable HTTP.

https://mcp.ember.dev/v2/mcp

Clients without remote support can run npx -y ember-mcp with EMBER_API_KEY set.

One command finds every coding agent on this machine and adds the Ember skill and server to each.

$npx -y ember-cli@latest init --all --browser

Takes about 20 seconds. Re-run it after installing a new agent.

Build directly with the API

Scrape your first page now. No account or API key is needed for this request.

Add an API key when you need higher limits. See the Python SDK, Node SDK or API reference to build it into your application.

Requests without a key

Keyless requests share a limit of 10 scrapes per hour per IP address and skip stealth proxies. Responses are identical otherwise, so code you write now keeps working once you add a key.

Other ways to get started

Install the Ember CLI

One command installs the CLI, signs you in through the browser, and adds the Ember skill to every coding agent it finds.

Set up with an agent

If you work inside a coding agent, let it do the setup. Three steps, about a minute.

  1. Install the skill

    The skill teaches your agent when to search, when to scrape, and how to keep pages small enough for its context window.

    $npx -y ember-cli@latest init --agent claude-code

  2. Sign in from the browser

    The installer opens ember.dev/cli-auth. Approve the request and the key is stored in your system keychain, never in a dotfile.

  3. Ask for something on the web

    Try a task that needs fresh data. The agent picks the endpoint; you see each call in Activity logs.

Build and test directly

The Playground runs every endpoint in the browser and shows the exact request, so you can copy it into your code once the output looks right. Press ⌘ K anywhere in these docs to jump to an endpoint.

Tip: ask the assistant. It has read every page here and answers with code for your language.

What can Ember do?

SearchSearch the web and get the full content of every result. ScrapeTurn any URL into Markdown, HTML, a screenshot or structured JSON. InteractKeep working with a scraped page: click, fill forms, load more. CrawlFollow links across a site and scrape every page you allow. ExtractTyped JSON from one page or many, with a schema or a prompt. AgentDescribe the data you need; get it back with sources.

Why Ember?

  • LLM-ready output. Clean Markdown, typed JSON, screenshots and links, without navigation and cookie banners.
  • Handles the hard parts. JavaScript rendering, proxies, rate limits and dynamic content are handled for you.
  • Reliable. 99.95% uptime over the last 90 days, with automatic retries on flaky pages.
  • Fast. A median scrape returns in 1.4 seconds; cached pages in under 200 ms.
  • Agent-native. An MCP server, a skill for coding agents, and these docs as llms.txt.

Endpoints at a glance

Every endpoint takes JSON and returns JSON. Credits are counted per page or result; failed requests are free.1

EndpointReturnsCredits
/searchResults with the full content of each page1 per result
/scrapeMarkdown, HTML, links, screenshot or JSON1 per page
/interactA live browser session on a scraped page2 per minute
/parseMarkdown from PDF, DOCX and XLSX files1 per page
/crawlEvery page of a site, as a job1 per page
/mapThe URLs of a site1 per call
/extractTyped JSON from one or many pages5 per page
/agentSourced answers and dataShown before the run
