1Connect your agent
$ npx -y @ember/cli init --agent claude-code
$ ember providers enable northwind-people

Once enabled, your agent picks the right capability on its own. Ask for people at a company and it calls people/search, then emails/find if you need addresses.

2Or call it from code
import Ember from "@ember/sdk";

const ember = new Ember({ apiKey: process.env.EMBER_API_KEY });

const run = await ember.agent({
  prompt: "Find engineering managers at lumenapi.com with verified work emails",
  providers: ["northwind-people"],
});

console.log(run.output);
import os

1Parameters
organization_domainsstring[]required

Company domains to search within, for example ember.dev.

person_titlesstring[]optional

Job titles to match. Several titles widen the net.

q_keywordsstringoptional

Free text matched across the person and their company.

pagenumberoptionalDefault 1

Page of results, counted from 1.

per_pagenumberoptionalDefault 25

Results per page. Maximum 100. Each started group of 5 people costs 1 credit.

2Endpoint and response

Send the parameters as a JSON body with your API key as a bearer token. The response lists matching people, newest signal first.
