Foundations

One ink, one accent, a 4px grid and a short list of durations. Every component is assembled from the values on this page, so changing a token changes the whole product.

The ink ladder

Every neutral is the ink at an opacity. A hover is the next step up, a muted label is a step down. Because the steps are transparent they sit correctly on white, on the page, on a tinted card and in dark mode without a second palette.

Surfaces and lines

The page is off-white; objects on it are white. Depth is two steps, not a staircase: things either sit on the page or float above it.

Accent

One hue does all the pointing. It has a solid for fills, a darker text shade that passes AA on neutral surfaces, and washes for tinted backgrounds. Pick another palette in Tweaks to see every wash follow.

  • Accent appears on the primary button, the active nav item, links, focus, switches that are on, the lead chart series and "new / live" marks. If a screen has more than about five accent touches, remove some.
  • Accent text on a neutral surface uses --fd-accent-text. For ember it is the same orange as the fill (3.1:1), so keep it to short labels, links and figures, never sentences.
  • White on the ember solid is 3.1:1. It is used only for 14px/450 button labels and icons, which meets the 3:1 requirement for interface components; never set paragraph text on the accent.

Status

Five tones, each with a solid for dots and fills, a text shade, a tinted background and a tinted line. Status colour describes an outcome; it is never decoration.

Type

Geist for the interface, Geist Mono for anything a machine would recognise. 450 is the house weight: slightly firmer than regular, never bold. Display sizes tighten their tracking; small sizes do not.

  • A page has one display title. Sections use fd-h3; cards use fd-title.
  • Mono is for identifiers, keys, paths, endpoints, units, table headers and eyebrows. Never for sentences.
  • Figures use tabular numerals (fd-num, built into fd-stat) so columns and counters do not jitter.

Space

A 4px grid with four half steps (2, 6, 10, 14) for the inside of small controls. Related things sit 4–8px apart, a group 12–16px, sections 24–40px, page bands 48px and up.

Layout

Placing things on a screen uses three primitives and a short set of attributes. Markup never carries a pixel value: gaps come from the space scale, widths and heights from the size scale.

Radius

Radius grows with the size of the thing. A control is 10, the card that holds it 12, the dialog that holds the card 16. Nested corners always step down.

Elevation

Most things have none. Shadows are short and layered, and the floating ones carry their own 1px ring so they never need a border.

Motion

Five durations and five curves. Colour changes take 160ms; things that move take 220ms; things that arrive take 320ms. The spring is reserved for thumbs and toggles.

  • Under prefers-reduced-motion every duration token becomes 0 and the press scale becomes 1. Components need no special case.
  • Only things that report live work may loop: spinners, a live status dot, a streaming caret, one ambient texture per view.

Theming

Tokens use light-dark(), so a theme is one attribute and it nests: a dark panel inside a light page needs no extra CSS. Accent and density work the same way.
