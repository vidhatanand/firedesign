Thread and messages

The person's turn is a bubble on the right; the agent's is prose on the page, at reading size and measure, so long answers read like documentation. Actions appear under an answer on hover or focus, and always under the last one.

How do I crawl only the docs section of a site, and what does it cost?

Start the crawl at the docs root and limit it to paths under it with includePaths. Each page costs one credit, so a limit is also a budget.

Request

  1. Send POST /v2/crawl with url set to https://docs.ember.dev.
  2. Add "includePaths": ["^/docs/.*"] and a limit.
  3. Poll GET /v2/crawl/{id} or pass a webhook to be told when it finishes.

JavaScript

fire/js/agent.js wires everything above on load. It uses code.js for JSON trees, the view switch and copy feedback.

Export / eventWhat it does
fd:submitFired on .fd-composer when the person sends. detail.value is the trimmed text. Cancel it to keep the text.
fd:stopFired when the stop button is pressed while data-state="running".
fd:actionFired by message actions; detail.action is copy, retry, up, down or open.
setRunning(composer, on)Switches the send button between send and stop.
stream(el, html, opts)Types HTML into el word by word with a caret. opts.speed (ms per word), opts.keepCursor, opts.signal. Returns a promise.
appendMessage(thread, role, html)Adds a user or assistant turn with an entrance rise.
setToolcall(el, { state, meta })Moves a tool call between queued, running, done, failed and approval.
demoRun(thread, opts)Plays the scripted run. opts.prompt, opts.instant. stopDemo(thread) stops it.
