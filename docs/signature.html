Foundations

Texture & frame

Fire's signature is type used as texture: fields of punctuation, letters or small shapes whose density follows a generated luminance field, set at very low contrast behind heroes, banners and empty states. Every field is procedural and seeded by its name, so a page always looks the same, and every field is decoration only, so it adds depth without adding anything to read. The theme holds it as one set of dials, so a product changes its signature in one place.

The signature, as dials

The texture is not set field by field: the theme record holds one signature, six dials that restyle every hero, glyph, loader and frame at once. Each is written as an attribute on <html>, only where it differs from the default, and every unpinned texture takes the page's value over its own option. A dial left on auto changes nothing; a texture pinned with data-signature="own" ignores them all. Open Tweaks above and change the Signature section: the unpinned textures on this page follow, the pinned specimens do not.

In a theme record

  • expandTheme() and themeToCss() write the attributes; Tweaks writes the same ones, stores them with the other tweaks, and Copy CSS and Copy theme include them.
  • Per option, in order: a texture pinned with data-signature="own" keeps all its own options; otherwise a page dial that is set (not "auto") wins over the texture's own option; otherwise the texture's own option; otherwise Fire's default. Set the page field to contour and every unpinned hero becomes contour.
  • Pin a specimen whose field or mark is the point, such as the grid and the field specimens on this page. Heroes in templates stay unpinned, so a theme restyles them.

  • The field fills its positioned parent and paints between the parent's background and its content. Use data-inline and a height to put one in normal flow.
  • Waves, orbit, rain and flame animate at 12 frames a second by default; terrain, grid and halftone are still unless you add data-animate. Animation pauses off-screen and in background tabs, and is a single still frame under reduced motion.
  • The same name always draws the same picture. Change data-seed for a different one, data-ramp for other characters, data-style="dots" to draw any field as halftone discs.

Marks

Characters and dots were the only marks. Squares, plus signs and dashes join them: each is drawn in the texture's colour at the size its place on the ramp asks for, so any field can be drawn in any of the five. data-style on one texture, data-signature-mark on the page.

data-style="squares"
data-style="plus"
data-style="dashes"
  • Squares grow with the level's square root, plus signs lengthen their arms, dashes lengthen; dots grow as discs. Every mark is a pixel-aligned shape drawn once into an atlas, so the cost is the same as characters.
  • Marks have no letters in them, so they suit a quiet, graphic brand. Characters stay the default.

Tones

Neutral is the default and right almost everywhere. Accent is for one small moment on a page; contrast is only for a field drawn on an accent or inverse surface.

neutral
data-tone="accent"

data-tone="contrast"

  • Tone is CSS: the field takes its element's color and opacity, and redraws when the theme, the accent or the OS colour scheme changes.
  • Neutral ink is 24% in light and 16% in dark, which keeps every field under about 1.6:1 against its surface.

Interactive

With data-interactive, characters near the pointer step up the ramp in a soft radius. Use it on one hero or landing surface where the texture is the subject, never on working screens.

Rules

Do

Use one field per view, at the edge of the composition: a hero's far side, an empty state's middle band, a banner's flanks. Leave most of the field empty.

Don't

Put a field behind paragraphs, tables, forms or code, raise its contrast to make it "show", or animate more than one field on a screen.

  • Texture is always decorative: aria-hidden="true", no pointer events, nothing a reader would miss.
  • Contrast stays under about 1.6:1 against the surface it sits on. If it competes with the content, it is wrong.
  • Under reduced motion every field is a single still frame, shimmer becomes plain text and spinners stop.
