Endpoints

Every endpoint takes JSON and returns JSON. Failed requests are free.

API reference
POST/v2/searchSearch the web with full page content per result. POST/v2/scrapeOne URL to Markdown, HTML, links or JSON. POST/v2/interactClick, type and extract in a live session. POST/v2/parsePDF, DOCX and XLSX files to Markdown. POST/v2/crawlEvery page of a site, as one job. POST/v2/mapAll the URLs of a site in seconds. POST/v2/extractTyped JSON from one page or many. POST/v2/agentDescribe the data; get it back with sources.
