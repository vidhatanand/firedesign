Brand

The brand is a mark and a name. When customers bring their own, the mark can be an image, a wide logo can stand in for both, and a wordmark can sign a page in a line of text.

  • An image mark is drawn at 24px in the same 36px box as an inline mark, so it survives the collapsed rail.
  • .fd-brand-logo is 32px tall and as wide as it needs, up to 160px. It cannot shrink to the rail: use it on a centred screen, or in a sidebar that does not collapse.
  • .fd-wordmark takes the current colour, so it reads as text. data-size="sm" sits in a caption; data-tone="accent" is for the brand itself.

  • The product sets its brand once, as <script type="application/json" data-fd-brand> in the page or setBrand(brand), and every .fd-brand follows: the sidebar head, the top bar, a centred screen, the docs top bar. The same JSON as an attribute on any element brands only what is inside it, as these three specimens do. All three start as the Ember brand and are filled when the page loads.
  • name is the text and the logo's alt. mark is a picture for the mark slot; without it the mark is the dot-matrix initial of the name. logo (a string, or { src, width, height }) replaces both with an img that carries width and height. logoDark takes its place when the page is dark: switch the theme to see the third one change. href sets the link. Pictures pass safeImageUrl(), so a refused address leaves the mark as it was.
  • A brand that must stay as written (a partner's mark, a wordmark) takes data-fd-brand-keep. For an email, give the same name and logo to renderEmail({ brand: { name, logo } }) (logoUrl still works).
  • A product's brand belongs with its look: a theme record may carry brand: { name, mark, logo, logoDark, href }, and tweaks.set(fromThemeRecord(record)) calls setBrand() with it. Only the page's own pictures and data: images show that way; a picture on another host needs setBrand({ …, hosts }) from the page.

Toolbar

Search, filters and view controls on the left; export and create on the right. It wraps instead of scrolling, and the search takes a full row on phones.

  • The toolbar wraps by its nearest container: the page in an app, or put it in fd-cq elsewhere. With a search, an end group and filters, it stays on one line while they fit. When they do not, the search and the end group share the first line and the filters move together to the second. Tab order stays search, filters, end.
  • How wide "fits" is depends on the number of filters: one, two, three, or four or more (780, 940, 1,110 and 1,280px). Under 640px the search takes a line, the filters become one row that scrolls sideways with a fade, then the end group follows.
  • fd-toolbar-filters is an optional wrapper around the filters. For a table with many fields, one combined filter replaces the row of chips.

Initial mark

Where an organisation has no logo, draw its first letter as a small dot-matrix glyph: lit dots in the box's colour, unlit ones faint, so it reads as a tiny display. The same name always gives the same glyph and the same tone, so an organisation keeps its mark on every screen. Use it in the brand slot, in tiles and avatars of organisations, and in email.

Quarry Labs Northwind
  • data-fd-initial="Quarry Labs" on a .fd-tile, .fd-avatar, .fd-account-avatar or .fd-brand-mark draws the mark. Leave the value empty and the box's own text is the name. Without script the box keeps its letter, which a tile and an avatar already style.
  • A tile or avatar without data-tone takes the tone its name maps to (accent, info, violet, success, warning or neutral; never danger). Give data-tone to choose one. A brand mark keeps the accent. The box is named after the organisation (role="img") unless it is aria-hidden.
  • Letters A to Z and digits draw their own glyph; accents are dropped ("Élan" draws an E); anything else draws a diamond. Below 28px the dots are too small to read: use a tile of 28 or more, or the letter.
  • For a server or an email: import { initialMark, initialRows, initialTone } from "fire/js/initial.js". initialMark(name) is an SVG string in currentColor ({ label: true } names it); initialRows(name) is seven strings of five 0 and 1 cells, for a mail client that draws no SVG; initialTone(name) is the tone. No DOM is needed. In a page, shell.setInitial(host, name) redraws a host.

  • command.records({ group, search, icon, min, delay, limit, palette }) registers a group and returns a function that removes it. search(query, { signal }) returns rows, or a promise of them: { id, label, hint, href, icon, keywords, perform, data }. Service status

Whether the product itself is healthy, in the top bar. When everything is normal it is an icon and nothing more; when it is not, it says so in words and a colour, because a quiet icon would be missed exactly when it matters.

  • .fd-service-status[data-status="operational|degraded|outage|maintenance"] is a link to your status page. Operational shows the icon alone in green, with the label for assistive technology and a tooltip; any other status shows the label in its tone. Rules

Do

Separate the sections of a page with bands. Use a card only when the thing inside is an object: a plan, a key, a provider.

Don't

Put a second primary button in the top bar, or colour nav items other than the current one. The sidebar is the quietest thing on the screen.
