# Fire class vocabulary (agreed names across families)

Use these exact names. If you own a family, implement every name listed under it (you may add more).
If you need another family's component in a demo, use its name from this list; it will exist.

- **Base (done)**: `fd-display fd-h1 fd-h2 fd-h3 fd-title fd-label fd-body fd-small fd-caption fd-stat fd-mono fd-mono-sm fd-eyebrow fd-muted fd-faint fd-link fd-icon fd-kbd fd-code fd-stack fd-row fd-grow fd-grid fd-divider fd-truncate fd-sr-only fd-rise fd-cq`
- **Buttons (done)**: `fd-btn` (`data-variant="primary|outline|ghost|inverse|accent-soft|danger|danger-soft"`, `data-size="xs|sm|lg|xl"`, `data-icon-only`, `data-block`, `aria-busy`), `fd-btn-group`, `fd-btn-text`, `fd-fab`
- **Shell**: `fd-app` (root grid; `data-sidebar="expanded|collapsed"`), `fd-sidebar`, `fd-sidebar-head`, `fd-sidebar-body`, `fd-sidebar-foot`, `fd-brand`, `fd-nav`, `fd-nav-label` (section eyebrow), `fd-nav-item` (`aria-current="page"`), `fd-nav-group` (expandable), `fd-nav-badge`, `fd-usage-card`, `fd-account` (user row), `fd-topbar`, `fd-team-switch`, `fd-main`, `fd-page`, `fd-frame` (blueprint column with rails + crosshair marks), `fd-band` (a full-width framed section inside the frame), `fd-page-hero` (+ `fd-page-hero-art`), `fd-page-head` (compact title row), `fd-toolbar`, `fd-split` (content + side panel), `fd-panel`, `fd-mobile-nav`
- **Navigation**: `fd-tabs`/`fd-tab` (underline), `fd-segmented`/`fd-segmented-item` (sliding thumb), `fd-chip-nav`/`fd-chip` (icon + label category strip, scrollable), `fd-subnav`/`fd-subnav-item` (settings side nav), `fd-breadcrumb`, `fd-back`, `fd-pagination`, `fd-steps`/`fd-step` (wizard), `fd-toc`
- **Forms**: `fd-field` (`fd-field-label`, `fd-field-hint`, `fd-field-error`), `fd-input`, `fd-textarea`, `fd-select` (styled native), `fd-input-group` (`fd-input-affix`), `fd-search`, `fd-checkbox`, `fd-radio`, `fd-switch`, `fd-slider`, `fd-number`, `fd-combobox`, `fd-tag-input`, `fd-choice` (radio/checkbox card), `fd-secret` (masked value + reveal/copy/rotate), `fd-copy-field`, `fd-dropzone`, `fd-otp`, `fd-form-row` (label left, control right), `fd-form-actions`
- **Overlays**: `fd-menu`/`fd-menu-item`/`fd-menu-label`/`fd-menu-sep`, `fd-popover`, tooltips via `data-fd-tooltip="text"` (`fd-tooltip`), `fd-dialog` (`fd-dialog-head|body|foot`), `fd-sheet` (side drawer / bottom sheet), `fd-toast` (API `toast({title, description, tone, action})`), `fd-command` (⌘K palette), `fd-confirm` (type-to-confirm), `fd-hovercard`
- **Data**: `fd-table` (+ `fd-table-wrap`, `fd-th-sort`), `fd-list`/`fd-list-row`, `fd-kv` (key-value grid), `fd-stats`/`fd-stat-tile`, `fd-meter`, `fd-progress`, `fd-filter` (filter trigger chip), `fd-filter-bar`, `fd-table-foot`
- **Content**: `fd-card` (`data-interactive`), `fd-badge`, `fd-status` (dot + label, `data-tone`, `data-live`), `fd-tag`, `fd-avatar`/`fd-avatar-stack`, `fd-tile` (logo/glyph tile), `fd-callout`, `fd-banner`, `fd-empty`, `fd-accordion`/`fd-disclosure`, `fd-timeline`, `fd-setting` (settings row: text left, control right), `fd-plan` (pricing/plan card), `fd-feature-list`, `fd-verified`
- **Code**: `fd-codeblock` (`fd-codeblock-head`, tabs, copy), `fd-snippet` (one-line command + copy), `fd-json` (collapsible tree), `fd-log` (log/terminal viewer), `fd-diff`, `fd-endpoint` (method + path pill), `fd-schema` (params table)
- **Agent**: `fd-composer`, `fd-composer-tools`, `fd-model-chip`, `fd-suggestions`, `fd-thread`, `fd-message` (`data-role="user|assistant"`), `fd-toolcall`, `fd-reasoning`, `fd-sources`/`fd-citation`, `fd-run-steps`, `fd-cursor` (streaming caret), `fd-playground` (request/response), `fd-session-list`

- **Texture & loading**: `fd-ascii` (`data-fd-ascii="terrain|waves|orbit|rain|grid|flame"`, fills its parent), `fd-dotgrid`, `fd-spinner`, `fd-braille`, `fd-dots`, `fd-skeleton` (+ presets `fd-skeleton-text|title|avatar|button|card|table|stat|chart|thread`), `fd-shimmer`
