Scrape endpoints

Scrape

Scrape one URL and get its content as Markdown, HTML, links, a screenshot or structured JSON.

Capabilities

Capabilities is the single page that lists what a scrape can do to a page, which of those run in a self-hosted deployment, and which endpoints accept a request with no API key.

Interactions

For browser interactions such as clicking, typing and navigating, use the Interact endpoint. Scrape a page first, then call POST /v2/scrape/{scrapeId}/interact with a plain-language prompt or code to act on the page.

For a few fixed steps you can also pass actions here, though it is not meant for long or branching flows.

Cached by default

A page scraped in the last two days is served from cache and costs the same. Set maxAge to 0 to always fetch it fresh.

Authorizations

Authorizationstringheaderrequired

Bearer authentication header of the form Bearer <token>, where <token> is your API key. Keys start with em-.

Headers

Idempotency-Keystringoptional

A unique value, such as a UUID. Retrying with the same key within 24 hours returns the first response instead of scraping again.

Ember-Teamstringoptional

The team to bill, for keys that belong to more than one team. Defaults to the key’s own team.

Path parameters

None. Endpoints that act on a job, like Get batch scrape status, take its id here.

Query parameters

dryRunbooleanDefault false

Validate the request and return its credit cost without scraping.

A JSON Schema for the result. Without one, Ember infers a shape from the prompt.

What to extract, in plain language. Up to 2,000 characters.

onlyMainContentbooleanDefault true

Return only the main content, without headers, navigation, footers and cookie banners.

includeTagsstring[]

CSS selectors to keep, such as article or .pricing-table. Everything else is dropped.

excludeTagsstring[]

CSS selectors to remove before converting, such as #comments.

waitForintegerDefault 0

Milliseconds to wait after the page loads before reading it. Prefer a wait action with a selector when you know what to wait for.

timeoutintegerDefault 30000

Milliseconds before the request is abandoned. Between 1000 and 300000.

actionsobject[]

Steps to run on the page before it is read, in order. Up to 50 actions per request.

maxAgeintegerDefault 172800000

Serve a cached copy if it is younger than this many milliseconds. 0 always fetches fresh.

Response

200application/json
successboolean

true when the page was scraped. Check data.metadata.statusCode for what the site itself returned.

dataobject

The formats you asked for, plus metadata.

markdownstring

The page as Markdown, when markdown is in formats.

linksstring[]

Absolute URLs found on the page.

screenshotstring<uri>

A signed URL to a PNG, valid for 24 hours.

Extracted data that matches your schema.

Set when the scrape worked but something was off, such as a page that took longer than timeout to finish loading.
