Fire

A design system for developer, agent and AI products: consoles, playgrounds, catalogs, logs, billing and chat-style agent screens. Plain CSS and small ES modules. One ink, one accent, hairlines instead of boxes.

Eight rules

The look is the result of a few decisions applied everywhere. If something new follows these, it will look like it belongs.

01

One ink

Every neutral is the ink at an opacity. Fills, hovers, muted text and edges come from one ladder and invert for dark mode by themselves.

02

One accent, used sparingly

The primary button, the active nav item, links, focus, switches that are on, the lead chart series. Nothing else.

03

Hairlines, not boxes

Pages are a framed column cut by 1px lines with crosshair marks. Cards are for objects; sections are not cards.

04

White objects on an off-white page

Two levels of depth: things sit on the page or float above it with a shadow that carries its own ring.

05

450 is the house weight

Labels, buttons and nav at 450, headings at 500, body at 400. Big titles tighten their tracking. Nothing is bold.

06

Two voices

Sans for people, mono for machines: keys, paths, endpoints, units, table headers and small uppercase eyebrows.

07

Soft controls

A borderless 4% wash, 10px radius, 36px tall. Only the primary button has depth, so the eye always finds it.

08

Everything moves a little

160ms colour, a 98% press, thumbs that slide with a slight spring, content that rises 8px. Only live work loops.

What is in it

Thirteen component families, a texture engine, pre-built skeleton screens and twenty-one full screens.

Coming from Volt

Volt is structurally sound and visually flat. Fire keeps its discipline (tokens only, one primary action, real states) and changes the decisions that made it read as boring.

DecisionVoltFire
AccentThe accent token is the text colour; lime appears on one button per screen.One hue for action, selection, links, focus and live marks, each at a defined strength. Add data-palette="volt" to keep the lime.
Type scalePage titles 24px, sections 16px. Uppercase and letter-spacing are lint errors.40px display titles with tight tracking, 20px sections at weight 450, 13px navigation, mono uppercase eyebrows for labels and table headers.
Weight400, 500 and 600 with selected items in semibold.450 for every label, 500 for headings. Selection is shown by colour, never by weight, so nothing shifts.
NeutralsA fixed warm-stone palette with separate dark values.One ink at 20 opacities. The same step works on any surface and in both themes.
StructureBordered lists, underline tabs, 12px cards with a control border on every input.A framed column with hairline bands and crosshair marks; borderless soft controls; white inputs on an off-white page.
MotionOne 120ms duration; colour transitions are banned.Five durations and five curves, a press scale, sliding thumbs, entrance rises, all removed by reduced-motion at the token level.
CharacterNone beyond the logo. Empty states are an icon and a sentence.Generative character textures in page heroes, banners and empty states, and a mono second voice throughout.
Controls34px, outlined, neutral.36px (40px on touch), soft-filled; the primary button is the only control with depth.

Use it

No build step. Link one stylesheet and one module; pick single layers if you want less.

  • Serve the folder over HTTP (ES modules do not load from file://): npm run dev, then open /docs/index.html.
  • DESIGN.md is the contract for adding to the system; npm run audit checks icons, tokens, class names and links.
  • Fonts are Geist and Geist Mono (OFL); icons are a subset of Lucide (ISC). All are vendored.
