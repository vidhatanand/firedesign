Use Ember via CLI

One command installs the Ember CLI, signs you in and adds skills to your coding agents.

$ npx -y ember-cli@latest init
ember — init

SDKs

Call Ember from your own code. Your choice of language is remembered across this page.

curl -X POST https://api.ember.dev/v2/scrape \
  -H "Authorization: Bearer $EMBER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://docs.quarry.dev",
    "formats": ["markdown"]
  }'
import os
from ember import Ember

app = Ember(api_key=os.environ["EMBER_API_KEY"])

page = app.scrape("https://docs.quarry.dev", formats=["markdown"])
print(page.markdown[:280])
import Ember from "@ember/sdk";

const ember = new Ember({ apiKey: process.env.EMBER_API_KEY });
const page = await ember.scrape("https://docs.quarry.dev", { formats: ["markdown"] });

console.log(page.markdown.slice(0, 280));

Install Ember in Claude Code

Three steps. The installer adds the Ember skill and the MCP server.

  1. Run the installer

    $npx -y ember-cli@latest init --agent claude-code

  2. Sign in and pick a team

    Run this inside Claude Code, choose ember, and approve access in the browser.

    /mcp

  3. Ask it to use Ember

    Scrape docs.quarry.dev/changelog and list what changed

Install Ember in Codex

The installer registers Ember as an MCP server in your Codex config.

  1. Run the installer

    $npx -y ember-cli@latest init --agent codex

  2. Sign in

    Opens a browser so you can choose a team. No key is stored in your shell history.

    $codex mcp login ember

  3. Try a search

    $codex "Search the web for vector database pricing"

Install Ember in Cursor

Add the MCP server, then switch it on in Cursor’s settings.

  1. Run the installer

    $npx -y ember-cli@latest init --agent cursor

  2. Switch Ember on

    Open Cursor Settings, choose Tools and MCP, and turn on ember. Approve access in the browser.

  3. Ask the agent to use it

    Crawl docs.quarry.dev and summarise each guide

Install Ember in opencode

The installer adds Ember to your opencode config and skills folder.

  1. Run the installer

    $npx -y ember-cli@latest init --agent opencode

  2. Authenticate

    Opens a browser so you can choose a team.

    $opencode mcp auth ember

  3. Run a task

    $opencode run "Map every page on docs.quarry.dev"
