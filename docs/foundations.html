Foundations

One ink, one accent, a 4px grid and a short list of durations. Every component is assembled from the values on this page, so changing a token changes the whole product.

The ink ladder

Every neutral is the ink at an opacity. A hover is the next step up, a pressed fill the next again. Because the steps are transparent they sit correctly on white, on the page, on a tinted card and in dark mode without a second palette. Text takes the text steps in Contrast, not raw ladder steps.

Contrast

Text that carries information reads at 4.5:1 or more wherever it sits, in every palette, light and dark, at default and high contrast. Quiet things stay quiet through size, weight, case and spacing: a table header is small uppercase mono, a sidebar group label is small tracked caps, a count sits in the same step as its label.

Surfaces and lines

The page is off-white; objects on it are white. Depth is two steps, not a staircase: things either sit on the page or float above it.

Accent

One hue does all the pointing. It has a solid for fills, a darker text shade that passes AA on neutral surfaces, and washes for tinted backgrounds. Pick another palette in Tweaks to see every wash follow.

  • Accent appears on the primary button, the active nav item, links, focus, switches that are on, the lead chart series and "new / live" marks. If a screen has more than about five accent touches, remove some.
  • Accent text on a neutral surface uses --fd-accent-text, which reaches 4.5:1 on the page, on surfaces and on the 8% accent wash in every palette. For ember it is a deeper orange than the fill, because the fill itself is 3:1 as text.
  • The label on the accent fill, --fd-accent-contrast, reaches 4.5:1: white where white does, otherwise a near-black tinted toward the accent. Ember's orange takes the brown-black, like volt's lime and honey's amber. Never set paragraph text on the accent.

Status

Five tones, each with a solid for dots and fills, a text shade, a tinted background and a tinted line. Status colour describes an outcome; it is never decoration.

Status and chart colours

Every palette derives its own success, warning, danger and info, and its six chart series, from its accent, ink and page. The tones keep their meaning and lean toward the palette's temperature and energy; a tone in the accent's colour family moves until the two are told apart. Ember's status colours are the reference and do not change; its chart series 3 to 6 are derived like every other palette's.

Long names

fix/assay-r11-long-unbroken-branch-name-wraps-at-375px

  • Titles and headings (fd-title, fd-h1 to fd-h3, fd-display) break anywhere, so a branch name or test id wraps instead of clipping. Table names, key-value values and pipeline job names break only at the word edge, which leaves a column’s minimum width alone.
  • A page has one display title. Sections use fd-h3; cards use fd-title.
  • Mono is for identifiers, keys, paths, endpoints, units, table headers and eyebrows. Never for sentences.
  • Figures use tabular numerals (fd-num, built into fd-stat) so columns and counters do not jitter.

Space

A 4px grid with four half steps (2, 6, 10, 14) for the inside of small controls. Related things sit 4–8px apart, a group 12–16px, sections 24–40px, page bands 48px and up.

Layout

Structure decides how wide things are. A stack, a row, a grid and a bounded column place everything; components bring their own widths (a form's measure, a dialog's size, a table's columns). Markup never sets a width, a height or a pixel value.

Where widths come from

ThingIts width is decided by
A formfd-form and fd-form-cols stop at a readable measure (560px; data-size="sm | lg | full"). Fields fill the form or one column; data-span widens one.
A short controldata-fit on an input, input group, select or search sizes it to its content: the input's own size attribute, a select's longest option.
A setting rowfd-setting: text, then a control; anything else inside it takes the full row underneath. data-control="wide" gives the control column room for a field.
A table columnThe header cell: data-col="fit | sm | md | lg | fill". Long values use fd-table-trunc (data-size="sm | lg").
A loading placeholderfd-table-skeleton with data-size="2xs … xl": its length says what kind of value is loading.
A dialog, sheet, popover or panelIts own data-size.
A framed figurefd-corners with data-size="sm | md | lg | xl".
  • If something needs a width that structure does not give it, the answer is a grid, a column, or a size variant on the component, not a number in the markup.
  • An inline style may pass a token to a component parameter, a relative value (72%, 20ch) or a unitless number. node scripts/audit.mjs reports pixel values and width attributes in markup under inline.
  • These docs sometimes show a component inside a narrow preview frame. The frame belongs to the docs page and is left out of the markup you copy.

Radius

Radius grows with the size of the thing. A control is 10, the card that holds it 12, the dialog that holds the card 16. Nested corners always step down.

Elevation

Most things have none. Shadows are short and layered, and the floating ones carry their own 1px ring so they never need a border.

Motion

Five durations and five curves. Colour changes take 160ms; things that move take 220ms; things that arrive take 320ms. The spring is reserved for thumbs and toggles.

  • Under prefers-reduced-motion every duration token becomes 0 and the press scale becomes 1. Components need no special case.
  • Only things that report live work may loop: spinners, a live status dot, a streaming caret, one ambient texture per view.

Changing an icon

Fire draws each <i data-icon> once, at start. To change it afterwards, call setIcon(el, name) with the drawn icon, an element holding one icon, or an icon not yet drawn. Classes, size, aria-hidden and any label stay. Setting data-icon on a drawn icon does the same. An unknown name keeps the current drawing and warns once.

  • Change the label with the icon: a play and pause button is one control whose icon, word and aria-pressed move together.
