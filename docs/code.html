Components

Code & logs

Mono on a sunken well, framed by a faint hairline. Colour is reserved for meaning: a few syntax hues, a status tone on a log level or a method, and the accent only on the lines you are pointing at.

Code block

Use a code block for anything a developer will read or paste: a request, a config, a response. Name the file in the header when the code lives in one; number the lines and highlight a range when the prose refers to it.

  • The header holds either a filename or language tabs, never both. A block without a header floats its copy button in the corner.
  • Copy takes the raw text, not the rendered spans. The button shows a check and “Copied” for 1.4 seconds.
  • The gutter is sticky: line numbers and the highlight bar stay put while long lines scroll sideways. Wrap is a per-block toggle.

Language tabs

Offer the same request in each language the reader might use. The choice is remembered and applied to every block on the page, so switching to Python once switches the whole page.

  • Underline tabs are the default. The segmented variant (data-variant="segmented") suits a header that already carries a label.
  • Tabs follow the ARIA tabs pattern: ← → move and select, Home and End jump. Use data-sync="none" to keep a block out of the shared choice.

Collapsed

Long responses start folded so the page keeps its rhythm. The fade and the line count tell the reader how much is hidden before they open it.

  • data-collapse="240" sets the folded height in pixels. Blocks shorter than that never show the button.
  • “Show less” scrolls the block back into view if its top has left the screen.

Syntax

A small built-in tokenizer covers the languages Ember docs use: JSON, shell and cURL, JavaScript and TypeScript, Python. It is forgiving: anything it does not recognise stays plain text, and code that is already marked up keeps its spans.

  • Tokens: keyword string number function key punct comment, each a --fd-syntax-* token.
  • highlight(code, lang) returns the same spans as an HTML string for your own markup.

Snippet

A snippet is one command or one value the reader copies and leaves with: an install line, a skill URL, a key. When setup takes several commands, number them.

$ npx -y @ember/cli init --agent claude-code

$ pip install ember-py

Steps

  1. Install the CLI

    $ npm install -g @ember/cli

  2. Sign in and pick a team

    Opens a browser. No API key is stored in your shell history.

    $ ember login

  3. Add Ember skills to your coding agent

    $ ember skills add --all
  • The $ prompt is decoration: it is not selectable and never copied.
  • fd-snippet-em marks the one segment that matters; fd-snippet-dim quiets the rest. The accent well is for keys and skill links only.
  • A step marked data-state="done" swaps its number for a check.

Endpoint

Method and path together, wherever an API call is named: a docs heading, a log row, a usage table. The method carries a status tone so a destructive call is recognisable at a glance.

GET/v2/crawl/{id} POST/v2/scrape PUT/v2/monitors/{id} PATCH/v2/keys/{key_id} DELETE/v2/crawl/{id}
POST/v2/search POST/v2/extract GET/v2/agent/{run_id}/events POST/v2/agent
  • Tones: GET info, POST success, PUT/PATCH warning, DELETE danger. The tone is read from the tag; set data-method to override.
  • Path parameters in braces are emphasised automatically. Make the pill a <button data-copyable> to copy the path on click.

Collapsed and bare

  • Keyboard: Tab enters the tree, ↑ ↓ move between lines, → opens or steps in, ← closes or steps out, Enter toggles. The focused line shows its Copy and Path actions and Tab reaches them.
  • Clicking a folded line opens it. data-depth sets how many levels start open; data-truncate the characters shown before “+N chars”.
  • The switch (fd-viewswitch) shows the [data-view] panel of the same value inside the nearest [data-fd-views], or inside data-target.

Terminal

ember — crawl
$ ember crawl https://docs.ember.dev --limit 50
  • The Follow dot pulses green while new lines scroll in and turns amber when you have scrolled away; “Jump to latest” resumes.
  • The viewer follows the theme on a sunken well. It is never forced dark.
  • appendLog(el, { level, message }) adds a line; ANSI colour codes in the message become tone spans (fd-log-tone[data-tone]).

Diff

Show what a change does to a config or a prompt before it is saved: a monitor edit, a schema migration, a skill update.

  • Write the unified diff as text inside <script type="text/plain" class="fd-diff-src">; line numbers come from the hunk headers and each line is highlighted in data-lang.
  • The +/− signs and line numbers are not selectable, so a copied selection pastes as clean code.

Schema

Parameter lists for an endpoint. Required comes first, defaults are stated, enum values are listed as they are typed, and nested objects fold so the top level reads in one pass.

urlstringrequired

The page to scrape. Must be a full URL including https://.

formatsstring[]optionalDefault ["markdown"]

Output formats to return. Each format costs nothing extra except json, which uses an extraction credit.

markdownhtmlrawHtmllinksscreenshotjson
onlyMainContentbooleanoptionalDefault true

Drop navigation, footers and cookie banners before converting.

actionsobject[]optional

Steps to run in the browser before the page is captured, in order.

typestringrequired
waitclickwritepressscroll
selectorstringoptional

CSS selector for click and write.

millisecondsnumberoptionalDefault 1000

How long a wait step pauses.

locationobjectoptional

Where the request appears to come from. Affects prices, language and consent banners.

countrystringoptionalDefault "US"

ISO 3166-1 alpha-2 country code.

languagesstring[]optional

Preferred languages, in order, for the Accept-Language header.

timeoutnumberoptionalDefault 30000

Milliseconds before the request gives up. Maximum 300000.
